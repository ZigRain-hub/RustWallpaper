## О проекте

RustWallpaper помогает настроить живой рабочий стол без лишних действий: добавляй свои обои в коллекцию, переключай их горячей клавишей и выбирай подходящее качество.

Потребление оперативной памяти и нагрузка на видеокарту зависят от обоев, разрешения и настроек. Универсального значения для всех сцен нет.

## Возможности

- **Своя коллекция** — добавление и удаление видео, GIF и поддерживаемых PKG-сцен.
- **Быстрый выбор** — галерея обоев по `Alt + Q`; сочетание можно изменить.
- **Настройки качества** — выбор разрешения и FPS для PKG-сцен.
- **Несколько мониторов** — режимы отображения и отдельные PKG-сцены на двух экранах.
- **Настройка PKG** — импорт `project.json` и изменение доступных параметров сцены.
- **Переходы** — выбор эффекта и длительности при смене PKG-сцен на основном экране.
- **Трей и автозапуск** — приложение может продолжать работать в фоне и запускаться при входе в Windows.
- **Звук и скрипты** — настройки для поддерживаемых сцен.

> [!NOTE]
> Поддержка PKG зависит от конкретной сцены: некоторые эффекты, скрипты и параметры могут работать не так, как в Wallpaper Engine. Включай скрипты только для обоев из доверенных источников.

## Установка

1. Открой вкладку **Releases** в репозитории и скачай архив последней версии.
2. Распакуй его в удобную папку.
3. Убедись, что `rustwallpapr.exe` и `WebView2Loader.dll` лежат рядом, и запусти `rustwallpapr.exe`.
4. Нажми **«Добавить файл»**, выбери обои и нажми **«Применить»**.

Для PKG-сцен необходим **Microsoft Edge WebView2 Runtime**. Он обычно предустановлен в Windows 11. Доступность отдельных видеоформатов зависит от компонентов и кодеков Windows.

## Сборка из исходников

Потребуются Rust stable и инструменты сборки под Windows. Для GNU-сборки:

```powershell
cargo build --release --target x86_64-pc-windows-gnu
```

Готовый исполняемый файл находится в `target\x86_64-pc-windows-gnu\release\`. Для распространения GNU-сборки положи совместимый `WebView2Loader.dll` рядом с `.exe`. Для MSVC-сборки загрузчик может быть статически включён в исполняемый файл; WebView2 Runtime при этом всё равно требуется.
